RAM 是决定 WordPress 套餐是否足够用的资源——在缓存网站上，CPU 很少是第一个成为瓶颈的因素。将你的工作负载与下表匹配，选择就变得非常机械化：

- **2.5–3 GB ($25.88–$29.99/年)** — 默认推荐。小型企业网站、作品集，或者使用免费控制面板将几个低流量网站聚集在一起。
- **4 GB ($39.99/年)** — WooCommerce 和课程网站。WooCommerce 加上几个扩展程序在没有任何客户访问之前就可能闲置在 1 GB 左右，而像 LearnDash 这样的 LMS 插件也同样占用资源。4 GB 是商店的底线，而非奢侈品。
- **6 GB ($64.99/年)** — 代理机构将十几个低流量客户网站放在一个盒子上，使用像 CloudPanel 或 HestiaCP 这样的控制面板。

解释 RAM 在这里为何承载如此重任的逻辑：缓存插件使提供页面变得非常便宜，因此普通流量主要由静态任务消耗少量资源。真正消耗内存的是数据库、未缓存的动态请求和 admin 仪表盘——这正是购物车、结账页面和课程平台比博客需要更多余量的原因。

## 常见问题

### 1 GB RAM 真的够 WordPress 使用吗？

对于合适的网站来说，是的。带有缓存插件和 swap 文件的精简博客可以在 1 GB 的空间内舒适运行。一旦 WooCommerce、页面生成器或十几个插件进入画面，1 GB 就不再舒适了——2.5 到 4 GB 的层级才是诚实的答案。

### 如何在 RackNerd VPS 上安装 WordPress？

部署服务器，从模板列表中选择 Ubuntu 或 Debian，安装免费的控制面板或 LEMP 堆栈，将你的域名指向服务器，然后运行 WordPress 的设置向导。第一次大约需要一小时；之后大约 15 分钟。免费的控制面板通常通过 Let's Encrypt 自动处理 SSL 证书，这消除了设置中最容易出错的部分。

### 一个套餐可以运行多少个 WordPress 网站？

流量比许可证更能决定这一点——根本不存在许可证限制。粗略估计：2 GB 可承载两到三个低流量网站，4 GB 可处理大约十个小型网站，6 GB 则可轻松满足小型代理机构的投资组合需求。如果你的网站突然获得大量流量，请按比例缩减这些数字。

### 套餐续费时会发生什么？

账单依然按照你注册时的相同年度费率收取。没有续费涨价，也没有计算建议你迁移的提示。话虽如此，续费也是重新检查当前套餐是否仍能容纳你实际流量的好时机。
